## 1. 해결하려는 문제

정기적으로 약을 복용하는 70대 고령 사용자가 외출·집안일 등 일상생활 중에 복용 시간과 복용 여부를 기억에만 의존하기 때문에, 약을 빠뜨리거나 이미 복용했는지 혼동하는 불편을 겪는다.

## 2. 핵심 컨셉

약 등록부터 복용 확인까지 **큰 글씨와 단순한 화면**으로 제공하고, 사용자가 정한 시간에 복약 알림을 주는 설치 없는 웹앱.

## 3. 설치하기 (아이콘으로 바로 열기)

설치 파일은 필요 없습니다. 아래 방법으로 아이콘을 만들어 두면 주소를 입력하지 않고 열 수 있습니다.

| 기기 | 방법 |
|---|---|
| **안드로이드 · 크롬** | 앱을 연 뒤 **⋮ → 홈 화면에 추가(앱 설치)** |
| **갤럭시 · 삼성 인터넷** | **≡ → 현재 페이지 추가 → 홈 화면** |
| **아이폰 · 사파리** | **공유(□↑) → 홈 화면에 추가** |
| **Windows · 엣지** | **⋯ → 기타 도구 → 앱 → 이 사이트를 앱으로 설치** → '바탕 화면 바로 가기 만들기' 체크 |
| **Windows · 크롬** | **⋮ → 전송, 저장, 공유 → 페이지를 앱으로 설치** |
| **Windows · 직접 만들기** | 바탕화면 빈 곳 오른쪽 클릭 → **새로 만들기 → 바로 가기** → 앱 주소 입력 → 이름 '건강약속' |

> 💡 `.ico`, `.png` 같은 **아이콘 그림 파일**을 눌러서는 앱이 열리지 않습니다. 반드시 위 방법으로 만든 **바로가기**를 누르세요.
>
> 💡 약 정보는 기기마다 따로 저장됩니다. PC와 휴대폰에서 각각 등록해 주세요.

## 4. 사용법

| 하고 싶은 일 | 방법 |
|---|---|
| 약 등록 | 첫 화면 **＋ 약 추가** → 약 이름·복용 시간·먹는 요일 입력 → **저장** |
| 오늘 먹을 약 확인 | 첫 화면(**오늘**)에 시간순으로 표시 |
| 복용 기록 | 약 옆 초록색 **먹었어요** 버튼 → ✔ 표시로 바뀜 |
| 잘못 눌렀을 때 | 화면 아래 **되돌리기** 또는 약 옆 **취소** |
| 알림 받기 | **설정 → 알림 허용하기** (앱 화면을 열어 두어야 함) |
| 글씨 크게·고대비 | **설정 → 글씨 크게 / 고대비 켜기** |
| 기기 바꾸기 전 | **설정 → 백업 파일 저장**, 새 기기에서 **백업 불러오기** |

## 5. 화면 흐름

```
바탕화면·홈 화면 아이콘 (처음은 QR) ──▶ ① 오늘
① 오늘 ──[＋ 약 추가]──▶ ② 약 추가·수정 ──[저장]──▶ ① 오늘
① 오늘 ──(복용 시간)──▶ 알림 창 ──[먹었어요 / 10분 뒤 다시]──▶ ① 오늘
하단 탭: ① 오늘 ↔ ③ 약 목록 ──[수정]──▶ ② ↔ ④ 설정
```

## 7. 적용한 디자인공학 원리

- **행동유도성:** 첫 화면에는 큰 '먹었어요'와 '＋ 약 추가' 버튼만 둔다.
- **제약:** 이름·시간·요일이 없으면 저장되지 않고, 같은 약은 중복 등록되지 않는다.
- **피드백:** 저장·완료 때마다 안내 문구가 나오고, 시간을 오전·오후 글자로 풀어 보여 준다.
- **오류 방지:** 이미 먹은 약은 버튼 대신 ✔를 보여 중복 복용을 막는다.
- **되돌리기:** 완료·삭제 직후 7초 동안 되돌리기를 제공한다.

## 8. 데이터와 보안 · 비용

- **저장 위치:** 이 기기의 브라우저(localStorage)에만 저장한다. 서버·로그인이 없다.
- **개인정보:** 이름·연락처를 받지 않는다. 약 정보도 기기 밖으로 보내지 않는다.
- **API · 비용:** 외부 API와 API 키를 쓰지 않는다. 비용은 0원이며 카드 등록이 필요 없다.

## 9. 알려진 한계

- **알림:** 앱 화면(탭)이 열려 있을 때만 울린다. 휴대폰이 절전 상태이거나 브라우저가 종료되면 울리지 않을 수 있다.
- **기기 간 공유:** 데이터는 기기·브라우저마다 따로 저장되어, 다른 기기와 자동으로 공유되지 않는다. 기기를 바꿀 때는 백업 파일을 쓴다.
- **휴대폰 알림:** 휴대폰 화면이 꺼지면 울리지 않을 수 있고, 상단 알림 칸에는 나오지 않을 수 있다.
- **기록 삭제:** 브라우저 기록·사이트 데이터를 지우면 저장된 약 정보도 함께 지워진다.
